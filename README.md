FPGA-Based Real-Time Temperature Monitoring and Predictive Thermal Management System Using Intelligent Sensor Interfaces

Project Overview

This project is an FPGA-based real-time temperature monitoring and predictive thermal management system using intelligent sensor interfaces.

The system is designed to monitor temperature and provide the required thermal management response using FPGA and Verilog HDL.

Objectives

- Real-time temperature monitoring
- Temperature sensor interfacing with FPGA
- Temperature condition monitoring
- Thermal warning and control
- Predictive thermal management
- Design verification using Xilinx Vivado

Technologies Used

- FPGA
- Verilog HDL
- Xilinx Vivado
- Temperature Sensor Interface

Files

- "temp_monitor.v" – Verilog HDL source code
- "vivado-output.jpeg" – Vivado output screenshot
